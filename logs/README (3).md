# Session logs

The assignment requires the full transcript of every AI coding session
in this directory, so reviewers can see how the tool was directed and
where mistakes were caught.

**This directory does not yet contain a raw exported transcript.** The
development conversation for this project ran in a chat interface that
this repository's own tooling has no mechanism to export from
automatically — there is no "save conversation to file" action
available from inside the session itself. Before final submission, the
actual raw transcript needs to be exported from wherever the session
was conducted (e.g. the chat UI's own export/download/copy feature) and
placed in this directory as-is, unedited.

`debugging-summary.md` in this directory is **not** a substitute for
that raw transcript — it's a short, honest, human-written summary of
the two specific moments called out in `DECISIONS.md`'s "debugging
note" section, included here because it was explicitly asked for and
because it's useful context on its own. It should sit alongside the
full raw transcript, not replace it.
